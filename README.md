# Webベース マインドマップ & ナレッジ管理ツール

Google Drive をストレージとして活用し、リレーショナルデータ構造（7テーブルモデル）に基づいたビジュアル思考およびナレッジ管理を行うクライアントサイドWebアプリケーション。
ビジュアルキャンバス（マップ表示）、データグリッド（表表示）、および右属性編集パネルがリアルタイムに相互同期します。

## 主な特徴
- **無限キャンバス**: React Flow（@xyflow/react）を用いた直感的なノード・エッジ操作
- **ダイナミック接続**: 固定の接続点に縛られないノード間の自由な接続ライン構築
- **自動レイアウト**: Dagre アルゴリズムによるノードの階層的木構造整列
- **マルチビュー統合**: マップ表示、データグリッド（表表示）、詳細属性パネルの三方向リアルタイム同期
- **Undo / Redo 履歴機能**: `Ctrl + Z` / `Ctrl + Y` による全操作の復元・やり直し
- **データ永続化**: 7テーブル構造を完全保持した JSON インポート / エクスポート機能
- **プライバシー＆ローカルファースト**: サーバレス構造で Google Drive API によるローカル/クラウド管理（予定）

## テクノロジースタック
- **フロントエンド**: React 18, TypeScript, Vite (v6)
- **キャンバスエンジン**: @xyflow/react
- **状態管理**: Zustand
- **自動レイアウト**: Dagre
- **スタイリング**: Tailwind CSS v4, @tailwindcss/postcss
- **パッケージマネージャー**: pnpm
- **型安全性**: TypeScript (`import type` の厳格運用)
