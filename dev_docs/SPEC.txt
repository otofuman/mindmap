【1. アーキテクチャ概要】
本システムは、マインドマップを「リレーショナルデータベース（7テーブル）」として定義・管理する。
キャンバス上の視覚的変更およびテーブル上のデータ操作は、すべて Zustand ストアを経由して
単一の `MindMapDocument` 内の該当テーブルへリアルタイムに双方向反映される。

【2. データモデル仕様 (7テーブル構造)】
1. DocumentMeta (ドキュメントメタ情報)
2. SchemaConfig (カスタム列定義)
3. Topic (トピック主データ: id, title, detailMemo, customValues)
4. Connection (接続データ: id, sourceTopicId, targetTopicId, type, memo, customValues)
5. TopicDisplay (トピック描画情報: topicId, shape, position, size, backgroundColor, textColor)
6. ConnectionDisplay (接続描画情報: connectionId, lineColor, lineStyle)
7. CustomListMaster (選択肢マスター)

※ 型定義はすべて `src/types/mindmap.ts` で一元管理し、`import type` 構文を徹底する。

【3. 実装済みコンポーネント仕様】
■ キャンバス (MindMapCanvas / MindMapNode)
- ダブルクリックによるノード新規作成
- ノード選択時の Tab キーによる子ノード追加
- 全方向接続対応のダイナミック接続機能
- Dagre アルゴリズムによる「自動整列 (LR/TB)」
- キーボードショートカット (Ctrl+Z / Ctrl+Y) 対応

■ データグリッド (DataGrid)
- Vite v6 / Rolldown 環境との高い互換性を保証する軽量な標準 React/TS テーブル実装
- Topics / Connections のタブ切り替え表示
- キャンバスでのノード選択とテーブル行のリアルタイム連動ハイライト
- テーブルからの行削除アクション

■ 履歴管理 (Undo / Redo)
- `past` / `future` スナップショットスタックによるドキュメント状態追跡
4. MILESTONE.txt （進捗と開発ロードマップ）
