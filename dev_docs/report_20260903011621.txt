4. とりあえずで仮置きしたが再検討が必要なこと
----------------------------------------------------------------------
・MindMapCanvas.tsx におけるローカルステート（useNodesState / useEdgesState）の直接参照
  - 現在は React Flow 内部の Node / Edge 型で直接状態を保持している。
  - 今後、`src/types/mindmap.ts` で定義した 7 テーブルのデータ構造（Topic, TopicDisplay 等）と React Flow 表現との間をつなぐ双方向変換ロジック（Store / State Management）の構築が必要。
・初期ダミーノードのハードコーディング
  - コンポーネント内に直書きされているため、ドキュメント全体（MindMapDocument）からのロード・セーブ処理に統合する必要がある。

5. できたが条件があること
----------------------------------------------------------------------
・@xyflow/react の型インポート設定
  - `Connection` など一部の識別子は型定義（`type Connection`）として明示的にインポートする必要がある（通常インポートではビルド・実行時エラーが発生するため）。

・自動レイアウト機能の導入
  - dagre ライブラリを使用した木構造・ネットワークの自動配置アルゴリズムの実装
・アプリケーション状態管理（Zustand 等）の設計
