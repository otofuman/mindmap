ご自身で準備する開発環境（インストールするもの）と、ファイルの管理方法（ディレクトリ構成・Git管理）を整理してご案内します。

---

## 1. 準備する開発環境（PCへインストールするもの）

開発を始めるために、お持ちのPCへ以下を順番に導入します。

### 必須のツール

* **Node.js (LTS版 v20 以降)**
* JavaScript/TypeScriptを実行・ビルドするための基盤です。
* [Node.js 公式サイト](https://nodejs.org/) から「LTS（推奨版）」をダウンロードしてインストールしてください。


* **Visual Studio Code (VS Code)**
* コードを書くための無料のエディタ（開発環境）です。
* [VS Code 公式サイト](https://code.visualstudio.com/) からインストールします。
* **おすすめ拡張機能**:
* `TypeScript and JavaScript Language Features`（標準で入っています）
* `Prettier - Code formatter`（コードの見た目を綺麗に整える）
* `ESLint`（コードのエラーや良くない書き方をチェックする）




* **Git**
* コードの履歴管理（バージョン管理）ツールです。
* [Git 公式サイト](https://git-scm.com/) からインストールします。



### パッケージマネージャ

Node.jsを入れると標準で `npm` が使えるようになりますが、動作が高速な `pnpm` の使用をおすすめします。
ターミナル（コマンドプロンプトやPowerShell）で以下のコマンドを実行するだけで導入できます。

```bash
npm install -g pnpm

```

## 2. ファイルの管理方法

ソースコードは **Git（GitHubなど）** で管理し、作成したアプリケーションで扱うマインドマップデータは **Google Drive** 上で管理します。

### ① ソースコードのプロジェクト構造（フォルダ構成）

プロジェクト直下（例: `mindmap-app/`）のフォルダ構成案です。

```text
mindmap-app/
├── .github/              # GitHub Actions設定（自動テスト・デプロイ用）
├── public/               # 静的ファイル（ファビコンやアイコン画像）
├── src/                  # アプリケーションの全ソースコード
│   ├── assets/           # スタイルシートや画像
│   ├── components/       # UIパーツ
│   │   ├── canvas/       # マップ表示（React Flowキャンバス・ノード・エッジ）
│   │   ├── table/        # 表表示（DataGrid・カスタムセル）
│   │   ├── dialogs/      # ノード詳細編集や接続設定のモーダル
│   │   └── ui/           # ボタンや入力枠などの共通部品（shadcn/ui）
│   ├── types/            # TypeScript型定義（先ほど定義したJSON構造など）
│   ├── store/            # 状態管理（Undo/Redo、temp_history、データ保持）
│   ├── services/         # Google Drive API連携、エクスポート（Mermaid/PDF）
│   ├── utils/            # ループ検出(DFS)、自動レイアウトなどの計算ロジック
│   ├── App.tsx           # メイン画面コンポーネント
│   └── main.tsx          # アプリのエントリポイント
├── SPEC.txt              # 仕様書
├── PLAN.txt              # 開発プラン
├── index.html            # HTMLテンプレート
├── package.json          # 依存ライブラリの管理ファイル
├── tsconfig.json         # TypeScript設定ファイル
└── vite.config.ts        # Vite（ビルドツール）設定ファイル

```

### ② バージョン管理（Git）

ソースコードの編集履歴は Git を使って記録します。

1. **`git init`**: プロジェクトフォルダを作成し、Gitの管理下に置く。
2. **`.gitignore` の配置**: 依存ライブラリ（`node_modules/`）や環境変数（`.env`）など、Gitで管理しないファイルを指定する。
3. **GitHubとの連携**: GitHub上にリポジトリ（保管庫）を作成し、定期的に `git push` してバックアップします。

### ③ アプリが生成するマインドマップデータの管理

アプリ上で作成・編集したマインドマップファイルは、ユーザー自身の **Google Drive** に保存されます。

* **ファイル形式**: `.mmap.json`（独自拡張子を持たせたJSONファイル）
* **保存先ディレクトリ**: ユーザーがGoogle Drive上で任意に指定したフォルダ、またはアプリ専用フォルダ（`appDataFolder`）
